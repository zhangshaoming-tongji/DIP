## 四个实验的演示顺序与核心要点

### 例 1：频谱泄漏（一维离散序列与二维图像）

- 保持数字频率不变，在观察窗口内分别截取整数个周期与非整数个周期。
- 观察离散傅里叶变换（DFT）的幅度谱：截取整数个周期时，频谱采样点恰好对准狄利克雷（Dirichlet）核的主瓣峰值和过零点，能量集中在一对谱线上；截取非整数个周期时，窗口两端做周期延拓会出现相位跳变，能量会分散到邻近频率，这种现象称为频谱泄漏。
- 在二维图像中，观察水平方向周期变化的竖直条纹图像及其中心化幅度谱：截取非整数个周期时，频谱中的亮点会沿水平频率方向扩散。

对应输出图像为 `ex1_1d_*` 与 `ex1_2d_*`。

### 例 2：相位代表图像结构

- 分别对 Lena 和摄影师（Cameraman）两幅图像做中心化的二维离散傅里叶变换。
- 交换两幅图像的幅度谱与相位谱，再做二维离散傅里叶逆变换（IDFT），可以观察到重建结果的轮廓始终跟随提供相位谱的那一幅图像。
- 对照“只保留幅度谱（把相位全部置零）”和“只保留相位谱（把幅度全部设为 1）”的重建结果，进一步体会结构信息主要保存在相位中。

对应输出图像为 `ex2_*`。

### 例 3：用快速傅里叶变换计算图像滤波

对 Lena 图像分别使用高斯平滑卷积核与水平梯度卷积核，按下面五个步骤完成频域滤波：

1. 将原图像和卷积核都补零到同一尺寸，该尺寸取不小于“原图边长加上卷积核边长减一”的最小 2 的整数次幂；补零时，需要将卷积核的几何中心对齐到坐标原点并做循环卷绕。
2. 对补零后的图像和卷积核分别做二维快速傅里叶变换（FFT）。
3. 将图像频谱与卷积核频谱逐点复数相乘。
4. 对乘积结果做二维快速傅里叶逆变换（IFFT）。
5. 裁取左上角与原图尺寸相同的区域，得到最终滤波结果。

程序会把每一步的中间图像存盘，并与空域直接卷积的结果核对最大绝对误差，以验证两种方法在数学上等价。

对应输出图像为 `ex3_*`。

### 例 4：基于小波分解与重构的遥感图像融合

- 第一组：`pan.png` 是高分辨率全色图像（512×512 像素），`ms_color.png` 是低分辨率多光谱彩色图像（256×256 像素，边长为全色图像的一半）。
- 第二组：`pan_town.png` 由一幅含房屋、道路和植被的彩色遥感图转成灰度，分辨率仍为 512×512；`ms_town.png` 是同一幅彩色图在长和宽上各缩小为二分之一后的 256×256 图像。
- 对全色图像做一层二维哈尔（Haar）离散小波分解，得到一个低频近似子带（LL）和三个高频细节子带（LH、HL、HH）。
- 将彩色图像上采样后，按红、绿、蓝三个通道分别缩放到低频近似子带的尺寸，用它们替换全色图像的低频近似子带，同时保留全色图像的三个高频细节子带。
- 对替换后的四个子带做二维离散小波逆变换（IDWT），得到既具有彩色信息又具有清晰空间细节的融合图像。

对应输出图像为 `ex4_*`（山地）和 `ex4_town_*`（村镇）。重点观察 `ex4_fused.png`、`ex4_town_fused.png` 以及各自的子带图。

## 对学生的最低完成要求

1. 能够结合时域周期延拓的边界跳变，解释例 1 中“为什么截取非整数个周期会引起频谱泄漏”。
2. 能够根据例 2 的实验现象，说明图像的结构轮廓主要保存在幅度谱还是相位谱中。
3. 能够完整写出例 3 的五个计算步骤，并说明为什么要对图像和卷积核补零。
4. 能够说明例 4 中小波分解得到的四个子带分别代表什么，融合时替换了哪个子带、保留了哪些子带。
